# Audit Metadata Database

## Panduan Audit Terintegrasi

Database panduan audit berbasis metadata tagging
untuk memudahkan pengguna memahami jenis audit,
klausul, persyaratan, dan bukti audit.

## Jenis Audit
1. Audit CDM SKK Migas
2. Audit ISO 9001
3. Audit ISO 14001
4. Audit ISO 45001
5. Surveilans
6. Audit SIAP SELAMAT K3 SKK Migas
7. Audit PSAIMS
8. Audit ISO 50001
9. Audit SUPREME

## Fitur
- Penjelasan lengkap jenis audit
- Pencarian menggunakan metadata tagging
- Klausul dari umum ke khusus
- Checklist dokumen audit
- Status kesiapan audit
- Glosarium istilah audit
