Cara memasang:
1. Extract All ZIP.
2. Upload file hasil ekstraksi ke folder utama repository GitHub Pages, jangan ZIP.
3. Klik Commit changes.
4. Setelah deployment, buka halaman dengan Ctrl + Shift + R.

Jika memakai paket PATCH, unggah hanya 5 file: index.html, dashboard.css, script.js, audit-data.json, audit-data.js.

Pengingat: AuditAtlas adalah panduan edukatif, bukan protokol audit resmi perusahaan.
