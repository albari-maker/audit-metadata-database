# AuditAtlas v1.8 – Penyesuaian SUPREME dari PDF sumber (2018)

- File sumber yang dibaca: supreme.pdf (114 halaman, versi sambutan 30 November 2018). PDF tidak disertakan dalam paket website.
- Struktur yang dapat dikonfirmasi: 8 proses dan 191 ekspektasi bernomor.
- Kartu proses 1–8 diperbarui agar sesuai dengan proses di PDF.
- Database diperluas dengan 191 entri ringkasan ekspektasi (nomor dan halaman PDF). Bukan reproduksi penuh/ketentuan terkini.
- Tiga ringkasan peta SUPREME lama (yang tidak selaras dengan struktur 8 proses) diganti menjadi 8 proses sesuai PDF.
- Total database: 370 topik/klausul, dengan 37 kelompok pada Peta Audit.
- Dokumen yang dikirim berisi materi tahun 2018, bukan teks Pertamina Standard PS-S-023-440-2023. Jangan menyatakan kedua edisi identik tanpa verifikasi.
- Contoh bukti merupakan contoh edukatif; tidak ditarik sebagai daftar wajib dalam dokumen asli.
- Jangan unggah PDF asli atau data audit/risiko/pekerja perusahaan ke repository Public tanpa izin.

## Instalasi

Unggah `index.html`, `script.js`, `audit-data.js`, `audit-data.json` ke folder utama branch `main` repository GitHub, dan pastikan semuanya menggantikan versi lama. Terkadang pada antarmuka Upload Files, file harus dikomit dalam satu perubahan agar sumber datanya sama versi. Periksa `Actions` sampai deployment sukses, lalu `Ctrl+Shift+R`.

File `INDEX_SUPREME_191_EKSPEKTASI.csv` opsional dan membantu pemetaan di Excel.
