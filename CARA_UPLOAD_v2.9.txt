AuditAtlas v2.9 - Peta Audit berlatar PUTIH

Pembaruan hanya pada Peta Audit (Umum ke Khusus).
Posisi karakter dan kotak teks sesuai editor-overrides.css yang Anda kirim.

Cara upload:
1. Unduh ZIP, kemudian Extract All.
2. Buka GitHub repository albari-maker/audit-metadata-database pada branch main.
3. Unggah semua file website hasil ekstraksi ke root repository.
4. Commit changes lalu periksa deployment GitHub Pages.
5. Buka website dan tekan Ctrl + Shift + R.

Jika ingin pembaruan ringan, cukup ganti dashboard.css dan editor-overrides.css (serta index.html untuk perubahan versi/cache).
Warna putih dibuat di dashboard.css agar tetap ada meski file editor-overrides.css diekspor ulang.
