AUDIT v3.19 - EDITOR EVIDENCE DENGAN LINK FOLDER

PASANG WEBSITE (SATU KALI):
1. Unduh ZIP FINAL v3.19.
2. Klik Extract All pada Windows.
3. Upload seluruh FILE hasil ekstraksi, bukan ZIP, ke branch main/root repository GitHub.
4. Klik Commit changes; tunggu hingga GitHub Pages memperbarui website.
5. Buka website dan gunakan Ctrl + Shift + R jika cache lama masih tampil.

CARA EDIT LINK EVIDENCE:
1. Buka https://albari-maker.github.io/audit-metadata-database/?editor=1#jelajahi
2. Pilih Audit SUPREME, cari kode 3.7 (misalnya), lalu buka 3.7 Pelatihan HSSE.
3. Pada 3.7.1, cari bagian Bukti (Evidence). Klik tombol "Edit link".
4. Ganti judul evidence dan tempelkan link HTTPS folder/dokumen.
5. Klik "Simpan pratinjau" untuk meninjau hasil link pada browser sendiri.
6. Klik "Unduh File Link Evidence" di jendela detail atau panel Editor Evidence.
7. Upload file yang diunduh, yaitu audit-evidence-links.js, ke folder root GitHub.
8. Klik Commit changes lalu buka website publik. Teks evidence kini menjadi link.

CATATAN:
- Setiap edit berikutnya cukup menimpa audit-evidence-links.js dengan file yang diunduh dari editor.
- Simpan file hasil ekspor sebagai cadangan; jangan menimpa dengan versi kosong ketika mengunggah ulang website lengkap.
- Link tidak mengubah izin akses Google Drive/SharePoint. Hanya tautkan folder yang boleh diakses pengguna yang dituju.
- GitHub Pages ini publik. Jangan simpan dokumen rahasia, data pekerja, atau tautan internal tanpa izin perusahaan.
- Editor menyimpan pratinjau secara lokal di browser. Tidak ada login admin atau pengeditan otomatis pada GitHub.
