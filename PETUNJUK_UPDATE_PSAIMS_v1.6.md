# Pembaruan AuditAtlas v1.6 — Keterangan Audit PSAIMS

## Yang berubah
Hanya kotak keterangan **Audit PSAIMS** pada menu **Jelajahi Klausul**:
- **Acuan Pelaksanaan** dengan pedoman PHE A8-004/PHE04000/2021-S9 Revisi 0.
- **Summary** mengenai audit keselamatan proses dan integritas aset.
- **4 pilar utama dan 15 elemen PSAIMS** sesuai teks yang disampaikan.

Versi ini berbasis **AuditAtlas v1.5** dan **mempertahankan pembaruan CDM v1.4 serta SUPREME v1.5**.

## Pemasangan cepat di GitHub
1. Unduh file `AuditAtlas_v1.6_Update_Audit_PSAIMS.zip`, lalu klik kanan **Extract All**.
2. Unggah **hanya** `index.html` dan `script.js` ke folder utama branch `main` di repository `albari-maker/audit-metadata-database`.
3. Pastikan GitHub menunjukkan file yang diganti, bukan file duplikat di dalam subfolder.
4. Klik **Commit changes**. Tunggu deployment GitHub Pages di tab **Actions** hingga berstatus sukses.
5. Buka situs dan tekan `Ctrl+Shift+R`; pilih **Jelajahi Klausul → Audit PSAIMS**.

Tidak perlu mengganti `audit-data.js`, `audit-data.json`, `style.css`, `README.md`, atau Excel.

## Batasan verifikasi
Uraian PSAIMS dan penomoran 4 pilar/15 elemen **mengikuti data yang diberikan pengguna**; belum diverifikasi terhadap pedoman internal PHE yang berlaku. Website ini tidak menggantikan protokol resmi audit maupun bukti audit perusahaan.
