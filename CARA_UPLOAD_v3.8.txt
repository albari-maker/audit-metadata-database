CARA PASANG
1. Ekstrak berkas ZIP. Jangan mengunggah ZIP mentah sebagai satu file.
2. Pada repository GitHub, upload seluruh isi folder ekstraksi ke ROOT branch main.
3. Ganti file yang namanya sama, lalu Commit changes.
4. Periksa GitHub Actions sampai Pages selesai dibangun.
5. Buka website dan tekan Ctrl + Shift + R.
